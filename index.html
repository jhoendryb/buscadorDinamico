Response Adapter
La propiedad responseAdapter te permite adaptar la estructura de los datos devueltos por el servidor al formato esperado por el componente. Por ejemplo, si el servidor devuelve { items: [], count: 0 }, puedes definir la estructura de la respuesta como: (response) => ({ data: response.items, countPage: response.count }).
