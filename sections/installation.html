Instalación

Múltiples formas de instalar el componente según tu entorno de desarrollo.

Vía npm / pnpm

La forma recomendada para proyectos con bundler (Vite, Webpack, Rollup, etc.):

# Con npm
npm install buscador-dinamico

# Con pnpm (recomendado)
pnpm add buscador-dinamico

Luego impórtalo en tu JavaScript:

import { Search } from 'buscador-dinamico';
import 'buscador-dinamico/css/buscador-dinamico.css';

Vía CDN (UMD)

Para proyectos sin bundler o inclusiones rápidas:

<!-- CSS -->
<link rel="stylesheet" href="https://unpkg.com/buscador-dinamico/dist/css/buscador-dinamico.css">

<!-- JavaScript (UMD) -->
<script src="https://unpkg.com/buscador-dinamico/dist/buscador-dinamico.umd.js"></script>

<script>
  const search = new BuscadorDinamico.Search({
    element: '#my-search',
    data: [...]
  }).init();
</script>

Vía script tag (ES Module)

<link rel="stylesheet" href="./dist/css/buscador-dinamico.css">

<script type="module">
  import { Search } from './dist/buscador-dinamico.es.js';

  const search = new Search({
    element: '#my-search',
    data: [...]
  }).init();
</script>

Descarga manual

Puedes descargar los archivos directamente desde la sección de releases de GitHub:

  1. Descarga buscador-dinamico.es.js (módulo ES) o buscador-dinamico.umd.js (UMD)
  2. Descarga buscador-dinamico.css desde dist/css/
  3. Inclúyelos en tu proyecto

Estructura de archivos

Después de la instalación, tu proyecto debería tener:

tu-proyecto/
├── node_modules/
│   └── buscador-dinamico/
│       ├── dist/
│       │   ├── buscador-dinamico.es.js
│       │   ├── buscador-dinamico.umd.js
│       │   └── css/
│       │       └── buscador-dinamico.css
│       └── src/
│           └── css/ (estilos fuente)
💡
Con Vite

Vite detecta automáticamente los archivos CSS importados y los incluye en el bundle final.

Verificación

Para verificar que la instalación fue exitosa, abre la consola del navegador y ejecuta:

console.log(typeof BuscadorDinamico.Search); // "function" (UMD)
// o
import { Search } from 'buscador-dinamico';
console.log(typeof Search); // "function" (ES Module)

SSR (Server-Side Rendering)

La librería es compatible con entornos SSR (Next.js, Nuxt, SvelteKit, etc.). Ni el import del módulo ni el constructor acceden al DOM, por lo que el paquete se puede importar y construir durante el render en servidor sin errores. init() sí requiere el navegador y debe ejecutarse solo en el cliente.

En la práctica, el patrón recomendado es crear y inicializar la instancia dentro de un hook que corra solo en el cliente (useEffect, onMounted). Así, la sentencia completa new Search(...).init() se ejecuta exclusivamente en el navegador y no es necesario instanciar en el servidor.

React / Next.js

Usa useEffect para inicializar solo en el cliente:

'use client'; // Next.js App Router: marca el componente como cliente
import { useEffect, useRef } from 'react';
import { Search } from 'buscador-dinamico';
import 'buscador-dinamico/css/buscador-dinamico.css';

export default function SearchComponent({ data }) {
    const searchRef = useRef(null);

    useEffect(() => {
        searchRef.current = new Search({
            element: '#my-search',
            data: data,
            theme: 'clean-white'
        }).init();

        return () => searchRef.current?.destroy();
    }, [data]);

    return <div id="my-search" className="app-search"></div>;
}

Vue / Nuxt

Usa onMounted para inicializar solo en el cliente:

<template>
    <div id="my-search" class="app-search"></div>
</template>

<script setup>
import { onMounted, onUnmounted } from 'vue';
import { Search } from 'buscador-dinamico';
import 'buscador-dinamico/css/buscador-dinamico.css';

const props = defineProps({ data: Array });
let search = null;

onMounted(() => {
    search = new Search({
        element: '#my-search',
        data: props.data,
        theme: 'clean-white'
    }).init();
});

onUnmounted(() => search?.destroy());
</script>

HTML estático / SPA

Si no usas SSR, puedes inicializar directamente:

import { Search } from 'buscador-dinamico';
import 'buscador-dinamico/css/buscador-dinamico.css';

new Search({
    element: '#my-search',
    data: [...]
}).init();
ℹ️
Regla general

La seguridad SSR no viene de dividir la creación en dos fases, sino de ejecutar toda la inicialización (new Search(...).init()) dentro de un hook de cliente (useEffect, onMounted, onMount). El hecho de que el constructor no toque el DOM garantiza que importar el módulo o construirlo durante el render en servidor no produzca errores.
