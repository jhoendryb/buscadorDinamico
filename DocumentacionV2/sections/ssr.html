SSR (Server-Side Rendering)

La librería es compatible con entornos SSR (Next.js, Nuxt, SvelteKit, etc.). Ni el import del módulo ni el constructor acceden al DOM, por lo que el paquete se puede importar y construir durante el render en servidor sin errores.

init() sí requiere el navegador y debe ejecutarse solo en el cliente.

Regla general

La seguridad SSR no viene de dividir la creación en dos fases, sino de ejecutar toda la inicialización (new Search(...).init()) dentro de un hook que corra solo en el cliente (useEffect, onMounted, onMount). Así, la sentencia completa se ejecuta exclusivamente en el navegador y no es necesario instanciar en el servidor.

El hecho de que el constructor no toque el DOM garantiza que importar el módulo o construirlo durante el render en servidor no produzca errores.

React / Next.js

Usa useEffect para inicializar solo en el cliente:

'use client'; // Next.js App Router: marca el componente como cliente
import { useEffect, useRef } from 'react';
import { Search } from 'buscador-dinamico';
import 'buscador-dinamico/css/buscador-dinamico.css';

export default function SearchComponent({ data }) {
    const searchRef = useRef(null);

    useEffect(() => {
        searchRef.current = new Search({
            element: '#my-search',
            data: data,
            theme: 'clean-white'
        }).init();

        return () => searchRef.current?.destroy();
    }, [data]);

    return <div id="my-search" className="app-search"></div>;
}

Vue / Nuxt

Usa onMounted para inicializar solo en el cliente:

<template>
    <div id="my-search" class="app-search"></div>
</template>

<script setup>
import { onMounted, onUnmounted } from 'vue';
import { Search } from 'buscador-dinamico';
import 'buscador-dinamico/css/buscador-dinamico.css';

const props = defineProps({ data: Array });
let search = null;

onMounted(() => {
    search = new Search({
        element: '#my-search',
        data: props.data,
        theme: 'clean-white'
    }).init();
});

onUnmounted(() => search?.destroy());
</script>

HTML estático / SPA

Si no usas SSR, puedes inicializar directamente:

import { Search } from 'buscador-dinamico';
import 'buscador-dinamico/css/buscador-dinamico.css';

new Search({
    element: '#my-search',
    data: [...]
}).init();
ℹ️
Nota

La integración con frameworks también se cubre en la sección Ejemplos · React y Ejemplos · Vue. En SSR, la diferencia clave es que init() debe vivir dentro de un hook de ciclo de vida que solo corra en el cliente.
