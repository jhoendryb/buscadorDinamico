Ejemplos

Ejemplos prácticos de uso del componente en diferentes escenarios.

Importante: el contenedor raíz del buscador debe ser un elemento <search> con la clase app-search. La estructura interna (content-pagination-items, items-search) la crea automáticamente la librería, pero si proporcionas datos iniciales en el HTML, escribe los items dentro de esa estructura para que se reutilicen.

<search id="buscador" class="app-search"></search>

Estructura HTML generada

Cuando proporcionas un contenedor vacío, la librería genera automáticamente la siguiente estructura con soporte ARIA completo:

<search class="app-search app-search1">
    <div class="input-search input-search-app-search1">
        <span class="search-icon" aria-hidden="true">🔍</span>
        <input type="search" name="filterSearch"
            id="input-search-app-search1"
            class="filter-search-app-search1 filter-search form-control"
            placeholder="Ingrese palabra clave..."
            aria-label="Filtrar por Búsqueda"
            role="combobox"
            aria-expanded="false"
            aria-haspopup="listbox"
            aria-autocomplete="list"
            aria-controls="items-search-app-search1">
    </div>
    <div class="content-pagination-items content-pagination-items-app-search1">
        <ul aria-label="Resultados de búsqueda"
            role="listbox"
            aria-hidden="true"
            class="items-search scroll-personalize items-search-app-search1"
            id="items-search-app-search1">
            <li role="option" class="items" id="items-0-app-search1">...</li>
            <li role="option" class="items" id="items-1-app-search1">...</li>
            <li class="scroll-sentinel" role="presentation"
                aria-hidden="true"
                style="height:1px;visibility:hidden;padding:0;margin:0;"></li>
        </ul>
        <div role="status" aria-live="polite" class="pagination-items">
            <div class="items-counter">2 de 2</div>
        </div>
    </div>
</search>

Elemento semántico <search>

El contenedor del input se renderiza como un elemento <search> (HTML5 landmark), no un <div>. Esto mejora la semántica del documento y la navegación por lectores de pantalla.

Patrón ARIA combobox

El componente implementa el patrón ARIA combobox estándar para autocompletado:

Elemento Atributo Valor Descripción
<input> type search Habilita el botón de limpieza nativo del navegador
<input> role combobox Indica que es un control de autocompletado
<input> aria-expanded true / false Estado del panel — sincronizado por VisibilityManager
<input> aria-haspopup listbox Indica que abre un listbox
<input> aria-autocomplete list Indica que muestra una lista de sugerencias
<input> aria-controls ID del <ul> Conecta el input con su listbox
<span> aria-hidden true Oculta el icono decorativo de lectores de pantalla
<ul> role listbox Lista de resultados
<ul> aria-hidden true / false Visibilidad del panel — sincronizado por VisibilityManager
<ul> aria-label "Resultados de búsqueda" Label descriptivo del listbox
<ul> aria-activedescendant ID del item Item destacado por teclado — se agrega/remueve dinámicamente
<li> role option Cada item de resultado
<div> role status Región live para el contador
<div> aria-live polite Anuncia cambios al contador
<li> sentinel role presentation Sentinel de scroll, oculto de AT
<li> sentinel aria-hidden true Oculto de lectores de pantalla

VisibilityManager

El VisibilityManager es una máquina de estados finita (FSM) que sincroniza los atributos ARIA al cambiar de fase:

  • aria-expanded del <input> → true cuando abierto, false cuando cerrado
  • aria-hidden del <ul> → false cuando abierto, true cuando cerrado
  • Clases CSS: content-pagination-visible / content-pagination-hidden
  • Atributo hidden del panel cuando está cerrado

Al seleccionar un item, el panel se cierra inmediatamente via close({immediate: true}).

        <div class="result">
            <h3>${item.title}</h3>
            <p>${item.description}</p>
        </div>
    `
}).init();

Con eventos

import { Search } from './dist/buscador-dinamico.es.js';

const items = [
    { id: 1, nombre: 'Laptop HP' },
    { id: 2, nombre: 'Mouse Logitech' }
];

const search = new Search({
    element: '#app',
    data: items
}).init();

search
    .on('init', () => console.log('Componente listo'))
    .on('search', (data) => {
        console.log(`Buscando: ${data.searchTerm}`);
        console.log(`Resultados: ${data.totalResults}`);
    })
    .on('itemSelected', ({ item, close }) => {
        // 'item' es el elemento <li> del DOM, no el objeto de datos.
        // Puedes leer el texto renderizado o consultar el DOM del item.
        console.log('Item seleccionado:', item.textContent);
        close();
    })
    .on('pageChange', (data) => {
        console.log(`Página ${data.page}/${data.totalPages}`);
    });

Con caché y sort

import { Search } from './dist/buscador-dinamico.es.js';

const productos = [
    { id: 1, nombre: 'Laptop HP', precio: 999 },
    { id: 2, nombre: 'Mouse Logitech', precio: 29 }
];

const search = new Search({
    element: '#app',
    data: productos,
    cacheEnabled: true,
    cacheMaxSize: 100,
    cacheTtlSeconds: 600,
    sortBy: 'precio',
    sortOrder: 'asc'
}).init();

// Ordenar dinámicamente
document.getElementById('btn-ordenar').addEventListener('click', () => {
    search.sort('nombre', 'asc');
});

// Limpiar orden
document.getElementById('btn-reset').addEventListener('click', () => {
    search.clearSort();
    search.draw('');
});

// Reseteear estado completo
document.getElementById('btn-clear').addEventListener('click', () => {
    search.clear();
});

Integración con frameworks

React

import { useEffect, useRef } from 'react';
import { Search } from 'buscador-dinamico';
import 'buscador-dinamico/css/buscador-dinamico.css';

function SearchComponent({ data }) {
    const containerRef = useRef(null);
    const searchRef = useRef(null);

    useEffect(() => {
        searchRef.current = new Search({
            element: '#react-search',
            data: data,
            theme: 'clean-white'
        }).init();

        return () => {
            searchRef.current?.destroy();
        };
    }, [data]);

    return <search id="react-search" ref={containerRef} className="app-search"></search>;
}

Vue

});
